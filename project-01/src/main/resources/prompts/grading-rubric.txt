=== 자바 과제 채점 기준표 (Standard Rubric) ===

[채점 철학]
1. 동작 우선: 코드가 의도한 결과를 내는지가 가장 중요합니다 (80% 비중).
2. 스타일 존중: 변수명(a, b, tmp 등)이나 괄호 위치로 점수를 깎지 마세요.
3. 안정성 중심: 예외 상황에서도 안전하게 동작하는지 확인합니다.

[점수 배점표 (총 100점)]

1. ⚙️ 기능 정확성 (Functionality) - 60점
   - [Pass/Fail] 모범 답안과 결과값이 정확히 일치하는가?
   - 주의: 결과가 틀리면 전체 점수는 40점을 넘길 수 없습니다.
   - 로직이 맞다면 구현 방식이 달라도 만점입니다.

2. 🛡️ 코드 견고성 및 효율성 (Quality) - 30점
   - 하드코딩: 입력값 대신 고정 상수 사용 시 (-10점)
   - 불필요한 연산: 현저히 비효율적인 로직 존재 시 (-10점)
   - 데드 코드: 실행되지 않는 코드 방치 시 (-5점)

3. 🚫 치명적 결격 사유 (Penalty) - 10점
   - 컴파일 에러: 문법 오류로 실행 불가 시 (-10점)
   - 악성 코드: 욕설, 비속어, 공격적 언어 포함 시 (-10점)

[채점 예시]
- int a = 10; return a + b; -> ✅ 만점 (변수명 지적 금지)
- return 5 + 3; -> ❌ 감점 (하드코딩: 입력 변수 무시)
